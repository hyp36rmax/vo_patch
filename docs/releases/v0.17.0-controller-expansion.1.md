## Controller Expansion 1

Controller profiles, physical input capture and independent player assignment for Cyber Troopers Virtual-On PC, built on Pairomaniac's V-On Patcher.

### Included

- Twin-Stick (Custom): twelve remappable inputs with Brook/XInput reference defaults, direct press-to-bind capture and separate saved P1/P2 layouts.
- Tanita Twin-Stick: native HID support for VID 1F4F / PID 9001 / revision 0200, digital lever translation and working trigger/top-button dash controls.
- Xbox 360 HORI Twin Stick EX: D-pad left lever, right-thumbstick right lever, independent triggers and shoulder-button dash.
- Explicit Start/Options controller selection, mixed-controller routing and compatible assignment swaps without changing Windows connection order.
- Controller hardware records covering measurements, implementation, validation and a reproducible testing methodology.

### Compatibility and validation

Controller Expansion supports English retail / US–Global and Japanese rerelease executables. USA OEM and Japanese original retain upstream profiles and assignment.

| Area | Status |
| --- | --- |
| Tanita movement, triggers and top controls | Functionally tested |
| Tanita versus Tanita local play | P1 and P2 validated with two physical units |
| Xbox 360 HORI EX | Single-unit controls and P2 operation validated |
| Custom remapping, capture and reassignment | Functionally tested |
| Dual HORI | Pending |
| Dual-Tanita reconnect ordering | Not recorded |

Back/camera zoom and upstream control mappings are preserved. This release does not claim compatibility with the PlayStation HORI model.

### Downloads and installation

- **Windows:** download `v-on-patcher-v0.17.0-controller-expansion.1-win.zip`, extract it completely, and keep `_internal` beside the executable.
- **Python:** download `v-on-patcher-v0.17.0-controller-expansion.1-python.zip` and retain the supplied `input` and `net` directories.

Back up `v_on.ini` before restoring or repatching an existing installation. Apply **XInput gamepad support** to a pristine executable and select each player's profile in F7. The patcher installs its supplied 32-bit helper automatically. No game executable or disc image is included.

Controller ownership is selected each game session; after a detected disconnect, reselect through F7. Saved profiles and Custom layouts persist across launches. Custom consumes XInput controls; Tanita uses its own fixed native profile.

See the [controller documentation](https://github.com/hyp36rmax/vo_patch/tree/v0.17.0-controller-expansion.1/docs/controllers) for detailed results and limitations.
