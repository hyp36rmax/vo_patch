# Controller Expansion — Raphnet Twin-Stick Pre-Release

Adds two native HID profiles for original Sega Twin-Sticks through characterized
Raphnet adapters, with all Twin-Stick profiles grouped together in F7.

| Profile | Tested hardware | Input behavior |
| --- | --- | --- |
| Twin-Stick (Raphnet DC) | Dreamcast HKT-7500 + Raphnet Dreamcast-to-USB v1 (`289B:0008`) | Buttons on both levers; physical Start selects the controller; dedicated Pause remains independent |
| Twin-Stick (Raphnet Saturn) | Saturn HSS-0151 + Raphnet Saturn-to-USB v2 (`289B:0043`) | X/Y left lever and button-based right lever; physical Start selects the controller; no Pause control |

Both device-specific decoders feed Virtual-On's existing digital Twin-Stick
semantics. Upstream Gamepad, Twin-stick and keyboard profiles, Custom Xbox/Brook
defaults and optional remapping, Tanita and Xbox 360 HORI EX remain intact.

## Compatibility and validation

English retail / US–Global and Japanese rerelease support Controller Expansion.
USA OEM and Japanese original retain upstream profiles and assignment.

| Evidence | Status |
| --- | --- |
| All implemented profiles | 1P Validated; 2P Validated; mixed local VS Functionally Tested |
| Mixed Raphnet DC/Saturn local VS | Functionally Tested |
| Dual Tanita local VS | Functionally Tested |
| Dual identical Raphnet DC / dual identical Raphnet Saturn | Not Tested |
| Dual Xbox 360 HORI EX | Pending |
| Dreamcast adapter v2 | Manufacturer-documented HKT-7500 support; local physical validation Pending |

Raphnet hardware characterization covers individual controls, diagonals and
simultaneous inputs, with no observed rollover/input collision in the tested
combinations. Reconnect permutations, saved-profile persistence and a separate
DC in-game Pause/resume result are not individually recorded. Manufacturer
compatibility does not establish the v2 identity, HID report or button map.

## Downloads and installation

- **Windows:** extract `v-on-patcher-v0.17.0-controller-expansion.2-win.zip` completely and keep `_internal` beside the executable.
- **Python:** extract `v-on-patcher-v0.17.0-controller-expansion.2-python.zip` with its supplied `input` and `net` directories.

Back up `v_on.ini` before restoring or repatching. Apply **XInput gamepad support**
to a pristine executable, choose each player's profile in F7, then release and
press physical Start/Options to assign the intended controller. Ownership is
selected each session; after a detected disconnect, reselect through F7.
The patcher installs the supplied controller helper. No game files are included.

See the [hardware records](https://github.com/hyp36rmax/vo_patch/tree/v0.17.0-controller-expansion.2/docs/controllers)
for mappings and evidence boundaries. Built on Pairomaniac's
[V-On Patcher](https://github.com/pairomaniac/v-on-patcher), with controller work
and hardware testing by hyp36rmax; the MIT license is retained.
